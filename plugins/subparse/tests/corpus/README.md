# Test corpora

## wptvtt/

91 WebVTT files from [web-platform-tests](https://github.com/web-platform-tests/wpt),
3-Clause BSD License, copyright web-platform-tests contributors. The license text is in
[LICENSE-wpt.md](LICENSE-wpt.md), copied from the upstream `LICENSE.md`.

90 files come from `webvtt/rendering/cues-with-video/processing-model/support/` and
`test.vtt` from `webvtt/rendering/cues-with-video/processing-model/evil/support/`. They
were taken over from gst-subparse-rs unmodified, and every file's git blob hash matches the
upstream file at wpt commit `ce5ca39646886a9349fc42913f843ec6e1c8a36f` (2026-10-28).

The snapshots in `../golden/wptvtt/` are generated by `tests/wptvtt_golden.rs` from these
files. They started as gst-subparse-rs's goldens with the pango lines removed.

## Charset fixtures

gst-subparse-rs also tests charset decoding with the corpus of
[pysrt](https://github.com/byroot/pysrt) (`tests/static/`), which is GPL-3.0. Those files
are not copied here. `tests/corpus.rs` builds equivalent fixtures at test time from its own
reference text: UTF-8, its BOM-marked UTF-8, UTF-16 LE/BE and UTF-32 LE/BE variants, and a
BOM-less CRLF cp1252 transcode.
